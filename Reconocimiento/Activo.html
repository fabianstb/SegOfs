02
DNSRecon: La Navaja Suiza del DNS

Herramienta escrita en Python, indispensable para la enumeración de registros, transferencias de zona y recolección de información del espacio de nombres.

Enumeración Estándar (SRV, SOA, NS, MX, A, AAAA)
bash 
dnsrecon -d example.com
Transferencia de Zona (AXFR)

Solicita una copia completa de la zona DNS. Si está mal configurado, revelará toda la infraestructura.

bash 
dnsrecon -d example.com -t axfr
Fuerza Bruta de Subdominios

Diccionario personalizado para descubrir hosts no listados públicamente.

bash 
dnsrecon -d example.com -D /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-110000.txt -t brt
Búsqueda Inversa por Rango (Reverse Lookup)
bash 
dnsrecon -r 192.168.1.0/24
Expansión de TLD
bash 
dnsrecon -d example -t tld
Caminata de Zona DNSSEC (Zone Walk)

Extrae registros explotando registros NSEC en zonas aseguradas con DNSSEC.

bash 
dnsrecon -d example.com -z
Salida Estructurada (JSON/SQLite)
bash 
dnsrecon -d example.com -j resultados_dnsrecon.json

OWASP Amass: Inteligencia de Activos

El rey del descubrimiento pasivo profundo. Utiliza scraping, APIs y bases de datos WHOIS históricas.

Descubrimiento Pasivo Total
bash 
amass enum -passive -d example.com
Inteligencia Inversa (WHOIS)
bash 
amass intel -d example.com -whois
Descubrimiento de ASN
bash 
amass intel -org "Nombre de la Empresa"
amass intel -asn 8911,50313,394161

ASNs: Mapeo de Rangos IP

Un Autonomous System Number (ASN) identifica bloques de IPs administrados por una organización. Mapearlos permite descubrir toda la superficie de red del objetivo.

PlataformaURLNotas
Hurricane Electric BGPbgp.he.netCompleto: Whois e IP ranges
BGPViewbgpview.ioAPI gratuita disponible
IPInfoipinfo.ioASN por IP
ASN Lookupasnlookup.comAPI gratuita
IPv4Infoipv4info.comIP y ASN por dominio
Amass + BBOT
bash 
# Por nombre de organización
amass intel -org tesla

# Por ASNs específicos
amass intel -asn 8911,50313,394161

# BBOT agrega ASNs automáticamente
bbot -t tesla.com -f subdomain-enum

python 
import mmh3, requests, codecs

def fav_hash(url):
    response = requests.get(url)
    favicon = codecs.encode(response.content, "base64")
    fhash = mmh3.hash(favicon)
    print(f"{url} : {fhash}")
    return fhash

DNS Brute-Force
💡Resolvers confiables: Descargar desde public-dns.info/nameservers-all.txt y filtrar con dnsvalidator, o usar trickest/resolvers.
bash 
# massdns (muy rápido)
sed 's/$/.domain.com/' subdomains.txt > bf-subdomains.txt
./massdns -r resolvers.txt -w /tmp/results.txt bf-subdomains.txt
grep -E "tesla.com. [0-9]+ IN A .+" /tmp/results.txt

# gobuster
gobuster dns -d mysite.com -t 50 -w subdomains.txt

# shuffledns (massdns wrapper con wildcard support)
shuffledns -d example.com -list example-subdomains.txt -r resolvers.txt

# puredns
puredns bruteforce all.txt domain.com

# aiodnsbrute (async)
aiodnsbrute -r resolvers -w wordlist.txt -vv -t 1024 domain.com

Virtual Hosts & CORS
Fuzzing con ffuf
bash 
# Auto-calibración
ffuf -u http://10.10.10.10 -H "Host: FUZZ.example.com" \
  -w /opt/SecLists/Discovery/DNS/subdomains-top1million-20000.txt -ac

ffuf -c -w /path/to/wordlist -u http://victim.com -H "Host: FUZZ.victim.com"

# gobuster vhost
gobuster vhost -u https://mysite.com -t 50 -w subdomains.txt

# wfuzz
wfuzz -c -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-20000.txt \
  --hc 400,404,403 -H "Host: FUZZ.example.com" -u http://example.com -t 100
CORS Brute Force
bash 
ffuf -w subdomains-top1million-5000.txt -u http://10.10.10.208 \
  -H 'Origin: http://FUZZ.crossfit.htb' -mr "Access-Control-Allow-Origin" -ignore-body
